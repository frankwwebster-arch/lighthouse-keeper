# Kitchen Basic Assets V6 Option B source record

Kitchen Basic Assets V5 is the sole visual and geometric baseline for this
full-family review draft. Frank selected calibration Option B on 16 October
2026. The rejected former V6 is not read, recovered, copied, transformed or
imitated.

The deliverable is built deterministically by
`scripts/build_kitchen_basic_assets_v6_option_b.py`. Compatible tops are
constructed by `scripts/kitchen_countertop_option_b.py` from the machine-
readable authority in `data/kitchen_countertop_option_b_recipe.json`.

The built-in image-generation tool produced one reference-only family study
from the exact V5 run, selected B seam and V5 table/chair/bin/bowl sheet. It
helped confirm the intended visual balance but contributes no candidate pixel.
The normalized prompt is retained in `imagegen-prompt.txt`; the generated study
remains outside the repository under Codex generated images.

All V6 rasters remain review-only, versioned and reversible. Runtime sprites,
Final, manifests, Keeper sources and animations are protected inputs and are
not written by the builder.
