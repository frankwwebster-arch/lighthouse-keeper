# Prompt log

Built-in image editing was asked to brighten only the F8 jumper to match F7 while preserving all other geometry and transparency. The result was rejected as direct artwork because it redrew the Keeper. It remains in `sources/` only as colour evidence.

The V2 candidate uses a deterministic jumper-only mask and HSV quantile transfer from exact V1 F7 to exact V1 F8. No generated geometry is used.
