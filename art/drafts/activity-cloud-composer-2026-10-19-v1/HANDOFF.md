# Activity Cloud Composer V1 handoff

This is an immutable, reversible review-only recipe authoring tool. It inherits
all 68 V3 activity components and the exact Prime rear-work body/route, adds five
isolated BBQ components, and changes no inherited file.

The browser tool lets Frank:

- label an activity and the household asset to which it applies;
- choose and reorder four or five hashed vocabulary elements;
- preview the same package in open-radial and bubble/bustle treatments;
- classify the recipe as rear-work, rear-work-with-context or
  dedicated-pose-required;
- name a proposed SFX cue;
- save multiple drafts in local browser storage;
- import, copy or download deterministic, SHA-256-addressed recipe JSON.

Dedicated-pose recipes intentionally hide the generic rear-work Keeper. Local
drafts and exports do not approve, promote or wire a recipe. Runtime, Final,
Workbench, Kitchen and every V3 byte remain unchanged.

Verify with:

```sh
npm run verify:activity-cloud-composer-v1
```
