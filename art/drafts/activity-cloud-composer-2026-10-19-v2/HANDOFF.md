# Activity Cloud Composer V2 handoff

V2 is a one-token immutable extension of Composer V1. It adds
`hygiene-shampoo` to the shared hygiene vocabulary and otherwise inherits V1
exactly. The original Composer V1 page, catalogue, assets and register are not
edited.

The shampoo is a separately owned 256 × 256 transparent component. It can be
combined with any other four or five-element recipe and does not bake shower,
room, household-object, Keeper or SFX context into the image.

Verify with:

```sh
npm run verify:activity-cloud-composer-v2
```
