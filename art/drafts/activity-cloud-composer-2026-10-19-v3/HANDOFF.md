# Activity Cloud Composer V3 handoff

V3 is an immutable twelve-token extension of Composer V2. It adds a selectable
album-sleeve homage collection to the `music` family and otherwise inherits V2
exactly. Composer V1 and V2 pages, catalogues, components and registers are not
edited.

Every sleeve is a separately owned 256 × 256 transparent component. The images
use recognisable visual motifs, but contain no copied titles, band names,
logos, typography, photographs or real-person likenesses. The Nevermind homage
uses a fully clothed generic adult swimmer; it contains no child or nudity.

Verify with:

```sh
npm run verify:activity-cloud-composer-v3
```
