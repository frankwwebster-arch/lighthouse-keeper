# Activity Cloud Composer V4 handoff

V4 is an immutable notation-layer extension of Composer V3. It preserves all
86 V3 selectable components, the Prime rear-work body, the complete route and
the default recipe exactly. Composer V1–V3 remain unchanged.

Six independently owned 256 × 256 notation accents are derived from a strict
3 × 2 transparent source grid. Any selected component in the `music` family
enables three changing accents by default. Selection, position jitter and
rotation use a recorded FNV-1a seed derived from the recipe key and ordered
music selection; apparent randomness therefore replays deterministically.

The notation layer has its own checkbox and exported hash-pinned contract. It
is not baked into instruments, performers, album sleeves, the Keeper,
household assets or SFX.

Verify with:

```sh
npm run verify:activity-cloud-composer-v4
```
