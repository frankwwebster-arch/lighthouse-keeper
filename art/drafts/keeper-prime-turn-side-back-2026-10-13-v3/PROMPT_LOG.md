# Prompt log

Built-in image editing was asked to make all F8 standard-outfit colours match F7 while preserving exact rear geometry and transparency. The result was rejected as direct artwork because it redrew the Keeper. It remains in `sources/` only as colour evidence.

The V3 candidate instead uses six deterministic component masks and HSV distribution transfer from exact F7 onto exact F8 clothing pixels. No generated geometry is used.
