What “4×” means here

This is not a promise that the Keeper will appear this many centimetres tall on every device. The game uses a responsive 1200 × 760 scene (the 300 × 190 logical design stage multiplied by four), then fits that scene to the available phone, tablet or computer viewport. His final on-screen size therefore changes with the device and camera.

The right pane is only a fixed authoring ruler: 1 logical pixel = 4 CSS pixels at 100% browser zoom. The dashed 32 × 40 lp box is therefore exactly 128 × 160 CSS pixels; the standing body occupies about 38 lp / 152 CSS pixels inside it. Use it to judge proportions against stairs, rungs and doors—not as a literal device preview.

Why the old 38-lp stair placeholder cannot survive

A 60-lp rise inside 38 lp would require a very steep 57.7° flight and treads too short for the Keeper's 8-lp boots. The measured 105-lp core holds the 84-lp flight plus a full 10.5-lp standing/turning margin at both ends. The base 172-lp room plus stair core is 277 lp wide; the largest agreed 214-lp room tier plus core is 319 lp and should be handled by camera fit, never by rescaling the Keeper.
