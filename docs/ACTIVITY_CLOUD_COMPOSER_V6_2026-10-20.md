# Activity Cloud Composer V6 — loo callout extension

Date: 20 October 2026

Status: immutable, reversible review candidate; not approved, promoted or deployed

## Outcome

V6 preserves Composer V5's 146 selectable components, suggested-package metadata outside `using-loo`, deterministic musical notation, Prime rear-work body, complete approved route, default recipe and timing contract exactly. It adds three independently selectable bathroom-family elements:

- `bathroom-flush-handle` — a standalone brass-and-ivory cistern lever;
- `bathroom-loo-brush` — a standalone brush and ceramic holder;
- `bathroom-bad-smell` — a discreet family-safe comic odour cue.

The editable `using-loo` suggestion now contains toilet, toilet roll, flush handle, loo brush and smell cue. It remains `dedicated-pose-required`, so loading it automatically withholds the generic standing rear-work body.

## Separation and reversibility

- The three additions remain independent callout components; none is baked into the toilet, Keeper, household asset or another callout.
- Body visibility, ordered component selection, radial/bubble treatment, musical notation and SFX remain separate controls.
- V5 is unchanged. Rejecting V6 requires discarding only the V6 draft, page, set manifest and three V6-only archive objects.
- Runtime, Final, Kitchen and production assets are unchanged.

## Deterministic gate

Each accepted generated source has zero visible alpha on its outer edge. The builder isolates its single declared owner into a fresh 256×256 cell and records the source bounds, normalised size, offset and SHA-256. Every resulting component has:

- one owner;
- zero ambiguous pixels;
- zero unowned visible pixels;
- zero edge alpha;
- a measured 20-pixel transparent gutter.

Run:

```bash
npm run verify:activity-cloud-composer-v6
```

Exact accepted prompts, rejected-variant notes and source hashes are recorded in `art/drafts/activity-cloud-composer-2026-10-20-v6/PROMPT_LOG.md`.

## Approval boundary

V6 asks only whether these three bathroom callout elements and the revised editable loo package are suitable. It does not approve a dedicated loo pose, runtime wiring, sound effect or promotion.
