# Activity Cloud Composer V2

**Status:** immutable, reversible review candidate built 19 October 2026; not
approved, promoted, deployed or connected to runtime recipes.

## Change from V1

V2 preserves Composer V1's 73 components, Prime rear-work body, complete route,
default Garden BBQ recipe, 42-frame callout timing and interface behaviour. It
adds one isolated `hygiene-shampoo` component to the hygiene-family menu.

The shampoo token is an unbranded sea-glass and storm-blue bottle with a warm
cap and a small attached foam cluster. It has no Keeper, fixture, room,
furniture, text or other contextual pixel. The 1,312 × 1,199 generated source
has clear outer edges; deterministic registration places its single owned
component in a 256 × 256 transparent cell with at least a 16-pixel gutter.

## Boundaries

- Composer V1 remains immutable and independently discardable.
- The shampoo source, derived component, public review reference and archive
  object are SHA-256 pinned.
- Household asset, Keeper body, activity tokens and SFX remain separate.
- Runtime, Final, Workbench and Kitchen files are unchanged.
- Rejection consists of discarding only the V2 draft, public shell, set
  manifest and its single content-addressed object.

## Files and verification

- Review tool: `public/keeper-review/activity-cloud-composer-v2/index.html`
- Draft/source: `art/drafts/activity-cloud-composer-2026-10-19-v2/`
- Builder: `scripts/build_activity_cloud_composer_v2.py`
- Verifier: `scripts/verify_activity_cloud_composer_v2.mjs`

Run:

```sh
npm run verify:activity-cloud-composer-v2
```

The verifier rejects any V1 component, Prime body, route, default recipe or
timing change, and checks source-edge alpha, component ownership, transparent
gutter, hashes, archive resolution, preload/decode behaviour and the
non-promotion boundary.
